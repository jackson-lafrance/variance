# Agent Work Logs

This folder contains markdown logs documenting agent work. Each log must include:

- **Detailed timestamps** (ISO 8601, e.g. `2025-02-26T14:30:00Z`)
- **Descriptive titles** summarizing the work
- **Structured content**: decisions, changes, files touched, blockers, follow-ups

Example filename: `2025-02-26-add-settings-dark-mode.md`
